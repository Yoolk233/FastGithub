# 这份源码是怎么来的（还原说明）

> **1.2.1Fix2 补充**：下面说的是 1.2.0 源码的还原过程。1.2.1Fix2 在还原出的工程上做了三类改动：① 修「加速后 github.com 反而 404 / 超时 / 突然断连」——网页型域名只写复验出 `200~399` 的 IP，并新增 45 秒节点巡检自动换 IP；② 新增左侧栏与「设置」页（显示=调色，带返回按钮）；③ 版本号统一为 `1.2.1Fix2`。主界面原有控件、文案、尺寸未改动。

这份源码不是"照着截图重写一遍"的仿制品，而是从 `FastGithub.exe`（v1.2.0，单文件发布包，Avalonia 11.2.3 / .NET 8）里**逐类反编译还原**出来的工程。为了让你（和未来的贡献者）知道哪些部分是原样、哪些部分可能和发布版有细微差别，这里把过程和结论写清楚。

## 一、做了什么

1. **拆开单文件包**：单文件发布包末尾带一张内嵌文件表，按 `offset / size / compressedSize / flags / nameLen / name` 每条回溯，共取到 **199 个内嵌文件**，逐个按 deflate 解压并与声明长度比对，全部一致（说明没有损坏、没有额外注入）。
2. **反编译业务代码**：用 ILSpy 的 `ICSharpCode.Decompiler 10.1.1` 对 `FastGithub.dll` 反编译，得到 11 个业务类：
   `Program`、`App`、`MainWindow`、`MirrorWindow`、`Config`、`Node`、`Net`、`Hosts`、`Engine`、`Dns`、`MirrorStore`。
   → 这部分是**逐语句还原**，逻辑、常量、文案、超时值、正则、IPv4 池、hosts 标记全部与发布版一致。
3. **取回原始 `app.manifest`**：它作为清单资源原样保留在 dll 里，是**逐字拷贝**，不是重写（`requireAdministrator` / `permonitorv2` / Win10-11 supportedOS 全在里面）。
4. **还原界面 XAML**：Avalonia 编译 XAML 之后，原始 `.axaml` 文本**不会**留在 dll 里（只有编译产物 `CompiledAvaloniaXaml`）。所以 `MainWindow.axaml`、`MirrorWindow.axaml`、`App.axaml` 是根据 `!XamlIlPopulate` 方法里的**每一个属性赋值、每一层控件树、每一个 `Name` 注册**逆推重建的：尺寸、边距、圆角、颜色（含精确 ARGB）、字号、字重、列宽（`2.1*` / `1.3*` / `90` / `1.1*`）、`Classes.Add("accent")`、滚动条附加属性，都能和发布版对上。
5. **补回丢失的主题样式**：`Themes/Fluent.xaml` 在原包里没有单独留下可读文本，这里按"主按钮是实心主色、圆角、白字"的实际呈现重写了一份最小样式（`Button.accent` 及 hover/pressed/disabled 四态）。**这一份是重写的，不是原件**，配色可能与发布版有细微差异。

## 二、与原发布版可能存在的差异

| 项目 | 状态 |
| --- | --- |
| 全部业务逻辑、常量、文案、超时、IP 池 | 与发布版一致（逐语句还原） |
| `app.manifest` | 与发布版一致（原样取出） |
| 两个窗口的控件树、尺寸、颜色、列宽 | 与发布版一致（由 XAML IL 逆推） |
| `Themes/Fluent.xaml` 主题细节 | **重写**，可能配色微差 |
| 代码注释、命名（`num` → 有意义的名字）、格式 | 重新整理过，可读性更好，行为不变 |
| `MainWindow.axaml.cs` 的 `InitializeComponent` | 发布版由 Avalonia 源生成器生成，这里改成显式 `AvaloniaXamlLoader.Load(this)` + `FindControl`，效果相同 |
| 项目文件 `FastGithub.csproj` | 按依赖关系重建（Avalonia 11.2.3 / Desktop / Themes.Fluent / Controls.DataGrid），原 `.csproj` 不在包内 |

## 三、已验证 / 未验证

- **已验证**：
  1. 199 个内嵌文件全部解压并逐个比对长度、通过 zlib 校验；
  2. 反编译产物与 dll 中的类型一一对应（11 个业务类）；
  3. **C# 全部源码在还原这台机器上实际编译通过** —— 用 Roslyn 4.11 + .NET 8 参考程序集 + 从原发布包里取出的**真实 Avalonia 11.2.3 程序集**（`Avalonia.Base` / `Avalonia.Controls` / `Avalonia.Controls.DataGrid` / `Avalonia.Markup.Xaml` / `Avalonia.Themes.Fluent` / `Avalonia.Desktop` / `SkiaSharp`）做全量编译，结果 `Success=True`，**0 error、0 warning**，输出 44KB 的 `FastGithub.dll`；
  4. 4 个 XAML/XAML 样式文件均为合法 XML；XAML 里用到的每一个控件属性（`TextBox.Watermark`、`DataGrid.RowHeight`、`DataGridTextColumn.Width`、`ComboBox.PlaceholderText`、`ScrollViewer.*ScrollBarVisibility` 等 30 余项）都用反射在原包里的 Avalonia 程序集上逐个核对过，**全部存在**。

- **未验证**：
  1. **没有执行 `dotnet build` / `dotnet publish`** —— 这台机器没有 .NET SDK（官方与镜像下载均被限速到 30KB/s 级别，268MB 的 SDK 拿不下来）。所以"XAML 编译（XamlIl 生成控件树）"这一步没有真正跑过，只做了 XML 合法性 + 属性存在性核对；
  2. 没有和原发布版逐像素比对界面（没有原始截图可对照，只能保证控件树/属性值来自 IL 逆推）。

> 也就是说：**C# 有编译级保证，XAML 是"结构正确 + 属性正确"级别的保证**。你在装了 .NET 8 SDK 的机器上第一次 `dotnet build` 时，如果 XAML 报某个属性/选择器不认，多半是 `Themes/Fluent.xaml`（这一份是重写的），按报错改一行即可。

## 四、关于"这是不是抄的"

- 代码来自**你自己交付的那个 exe**，反编译你自己的程序不涉及他人版权。
- 但**思路与域名/IP 池的来源**参考了 `dotnetcore/FastGithub`（MIT）等公开项目，`README` 里已注明。若后续要更严谨，建议在 README 里补一句"本项目为独立实现，仅借鉴公开的域名列表与镜像预设"。
- 镜像站是第三方服务，本项目只是做链接拼接，不代理、不缓存任何内容；1.2.2 起不再内置任何镜像域名。
